# Modèles de messages

Les messages envoyés en dehors de la fenêtre de 24 heures doivent être des **modèles approuvés par Meta**. Range ici un fichier par modèle, en indiquant :

- le nom du modèle tel que déclaré chez Meta ;
- sa catégorie (Marketing, Utility, Authentication) ;
- la langue ;
- le texte avec ses variables `{{1}}`, `{{2}}`…

Exemple de fichier : `relance-j2-fr.md`.
